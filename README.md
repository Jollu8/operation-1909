# Operation №1909 💌

Необычный способ пригласить девушку на свидание — превратить приглашение в маленькую секретную операцию с шутками, неожиданными поворотами и планами на приятный вечер.

**[Открыть операцию → jollu8.github.io/operation-1909](https://jollu8.github.io/operation-1909/)**

Всё начинается с одной небольшой миссии. За пару минут она выбирает секретный позывной, отвечает на шуточные вопросы и решает, каким будет ваш вечер: кофе или коктейль, уютное место или прогулка, мини-свидание или встреча без названия.

Можно выбрать удобное время, добавить своё пожелание или довериться режиму «Сюрприз». В финале получается персональный протокол встречи — с торжественным одобрением операции и конфетти.

Согласие здесь не обязательный финал: от приглашения можно отказаться. Главное — подарить улыбку и предложить провести время вместе.

## Если хочешь попробовать для своего приглашения

Чтобы ответы приходили тебе, подключи свою форму в [Formspree](https://formspree.io/):

1. Зарегистрируйся и создай форму кнопкой **New Form**.
2. В разделе **Integration** скопируй адрес формы — он выглядит как `https://formspree.io/f/идентификатор`.
3. В своей копии [index.html](index.html) найди в функции `sendResult()` эту строку (сейчас это строка 182):

```javascript
const r=await fetch("https://formspree.io/f/xppwqaar",{
```

Замени адрес в кавычках на адрес своей формы:

```javascript
const r=await fetch("https://formspree.io/f/YOUR_FORM_ID",{
```

`YOUR_FORM_ID` — пример: вместо него должен быть идентификатор, который выдал Formspree. Остальную часть строки менять не нужно. Исходный адрес связан с формой автора, поэтому для своего приглашения используй собственный.
