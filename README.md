# Operation №1909 🎯

Небольшая интерактивная веб-страница-квест для необычного приглашения человека на свидание, кофе, коктейль или просто приятную встречу.

Вместо обычного:

> «Может, сходим куда-нибудь выпить кофе?»

человек получает ссылку на мини-игру в стилистике секретной операции.

Пользователь проходит несколько шуточных этапов, выбирает напиток, формат встречи, атмосферу, удобное время и в конце получает персональный **Operation Protocol**.

Проект сделан как один автономный `index.html` и не требует сервера, базы данных, npm или каких-либо JavaScript-фреймворков.

---

## ✨ Что умеет

Внутри есть:

* интерактивный сценарий с несколькими ветками;
* положительные и отрицательные варианты ответа;
* возможность нормально отказаться от приглашения;
* имя / псевдоним / секретный позывной участника;
* выбор напитка;
* выбор атмосферы встречи;
* выбор формата встречи;
* выбор дня и времени;
* дополнительное условие от участника;
* динамические системные сообщения;
* анимации и небольшие визуальные эффекты;
* `ORGANIZER.EXE IS NOT RESPONDING`;
* конфетти при финальном согласии;
* режим «Сюрприз» со случайным сценарием встречи;
* итоговый протокол встречи;
* сохранение незавершённой операции в браузере;
* восстановление прогресса после обновления страницы;
* управление с клавиатуры и фокус для основных экранов;
* автоматическая отправка результата через Formspree;
* таймаут сетевой отправки, чтобы интерфейс не зависал;
* просьба сделать скриншот результата как резервный канал связи;
* адаптация под мобильные устройства.

# 🚀 Быстрый запуск

## 1. Клонировать репозиторий

```bash
git clone https://github.com/Jollu8/operation-1909.git
```

Перейти в папку проекта:

```bash
cd operation-1909
```

После этого можно просто открыть:

```text
index.html
```

в браузере.

Никакой сборки или установки зависимостей не требуется.

## Сохранение прогресса

До финального подтверждения выбранные данные сохраняются только в `localStorage` браузера. При повторном открытии страницы можно продолжить незавершённую операцию или начать заново.

Локальные данные очищаются после подтверждения результата, отказа или ручного перезапуска операции. Если браузер запрещает `localStorage`, страница продолжит работать без сохранения прогресса.

# ⚙️ Настройка под себя

Перед тем как отправлять страницу кому-либо, рекомендуется изменить несколько вещей.

## 1. Formspree

Для отправки результатов используется Formspree.

Создайте свою форму:

https://formspree.io/

После создания Formspree выдаст endpoint примерно такого вида:

```text
https://formspree.io/f/xxxxxxxx
```

Найдите в `index.html`:

```javascript
fetch("https://formspree.io/f/XXXXXXXX", {
```

и замените адрес на свой:

```javascript
fetch("https://formspree.io/f/YOUR_FORM_ID", {
```

### Важно

Не используйте чужой Formspree endpoint из форка или оригинального репозитория.

Создайте собственный.

---

## 2. Название операции

По умолчанию используется:

```text
OPERATION №1909
```

Если хочется использовать собственное название, найдите в `index.html` все упоминания:

```text
1909
```

и замените их.

Например:

```text
OPERATION №2707
```

или:

```text
PROJECT COFFEE
```

или что-нибудь совершенно своё.

---

## 3. Тексты

Практически весь сценарий находится непосредственно в JavaScript внутри `index.html`.

Можно менять:

* приветствие;
* шутки;
* вопросы;
* варианты ответов;
* комментарии оператора;
* варианты напитков;
* варианты мест;
* дни;
* время;
* финальный текст.

Например:

```javascript
<p>
  Предложение простое:
  <b>ты + я + приятное место + напитки + хороший вечер.</b>
</p>
```

можно заменить на свой вариант приглашения.

Чем персональнее будут реплики, тем лучше работает идея страницы.

# 📧 Какие данные отправляются

После финального подтверждения JavaScript формирует результат и отправляет его через Formspree.

Пример:

```text
Operation №1909 — новый результат

Участник:
Agent K

Результат:
СОГЛАСНА

Напиток:
🍸 Коктейль

Атмосфера:
🕯 Тихое уютное место

Классификация:
👀 Свидание

День:
Пятница

Время:
Вечером

Дополнительное условие:
Место выбираешь ты
```

Отправка происходит только после финального подтверждения операции.

Запрос к Formspree ограничен таймаутом в 8 секунд. Если отправка не сработала, финальный экран всё равно остаётся доступным и предлагает отправить результат скриншотом.

# 🌐 Публикация через GitHub Pages

Самый простой способ разместить проект бесплатно — GitHub Pages.

## 1. Создайте репозиторий

Создайте новый репозиторий на GitHub.

Например:

```text
operation-1909
```

## 2. Добавьте файлы

Минимально достаточно:

```text
operation-1909/
├── index.html
└── README.md
```

## 3. Отправьте проект на GitHub

```bash
git add .
git commit -m "Initial Operation 1909"
git push
```

## 4. Включите GitHub Pages

В репозитории откройте:

```text
Settings
→ Pages
→ Deploy from a branch
→ main
→ / (root)
→ Save
```

После публикации сайт будет доступен примерно по адресу:

```text
https://YOUR_USERNAME.github.io/operation-1909/
```

---

# 👤 Если у вас уже есть `username.github.io`

Это не проблема.

Например, если основной GitHub Pages используется как персональная страница:

```text

```

создайте отдельный репозиторий:

```text
operation-1909
```

Тогда квест будет находиться отдельно:

```text
https://username.github.io/operation-1909/
```

а основная страница останется без изменений.

# 🖼 Добавление мемов и изображений

Если хочется добавить собственные реакции или мемы, лучше хранить изображения непосредственно в репозитории.

Например:

```text
.
├── index.html
├── README.md
└── assets/
    ├── reaction.webp
    ├── suspicious.webp
    └── victory.webp
```

Использовать их можно обычным HTML:

```html
<img src="assets/reaction.webp" alt="Reaction">
```

Лучше не перегружать квест изображениями: несколько реакций в ключевых местах обычно работают лучше, чем мем после каждого ответа.

# 🔒 Privacy

Проект не требует аккаунта от человека, который проходит квест.

В текущей концепции отправляется только итоговый подтверждённый пользователем вариант встречи.

Имя, выбранные параметры и дополнительное условие хранятся локально в браузере до завершения операции. После отказа или перезапуска локальное состояние удаляется.

# ❤️ Зачем вообще это существует?

Потому что написать:

```text
Пойдём выпьем кофе?
```

было слишком просто.

Поэтому был выбран очевидный инженерный путь:

```text
создать веб-приложение
→ придумать систему ветвлений
→ добавить анимации
→ подключить отправку результатов
→ разместить всё на GitHub Pages
→ получить ответ на вопрос,
  который можно было задать одним сообщением
```

Рациональность решения остаётся предметом дальнейших исследований.
